# 期刊文章池 · Journal Article Pool

2025—2026 经管顶刊文章池：中文三刊（经济研究、金融研究、管理世界）+ 十本英文顶刊研究论文，共 2,433 篇，中英双语检索与管理。

## 在线访问

- 上线后网址：`https://yuaenn0813.github.io/econfin-article-pool/`

## 功能

- 中英题名 / 作者 / 摘要 / 关键词 / DOI 全文检索，命中高亮
- 期刊（按语言分组目录）、年份、金融分类、研究方向、摘要覆盖筛选
- 逐篇中英摘要切换；表头点击排序；筛选状态存于网址 hash，可分享
- 收藏与思考记录：仅保存在**访问者自己的浏览器**（localStorage），不随仓库公开；支持"导出我的痕迹 / 导入痕迹"备份与迁移
- 筛选结果一键导出 CSV（UTF-8 带 BOM，Excel 直接打开）
- 深色模式（右上角切换，跟随系统）

## 数据口径

时间窗 2025-01-01 至 2026-07-29；去重优先 DOI；英文摘要提供中文工作译文（正式引用以英文原摘要为准）；期刊评级标签仅作识别参考。详细口径见页面底部"口径、字段与已知限制"。

## 更新方式

本仓库的 `index.html` 为单文件应用（内嵌文章数据）。数据上新或页面改版后重新生成并提交该文件即可，GitHub Pages 会自动更新线上版本。
